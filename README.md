A modern **To-Do List Android Application** built using **Kotlin**, **Jetpack Compose**, **MVVM architecture**, and **Room Database**.  
The app allows users to **add, edit, delete tasks** and shows a **popup dialog when a task is marked as completed**.

---

## 🚀 Features

- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- 🗑️ Delete tasks  
- ✅ Mark tasks as completed  
- 🔔 Popup dialog on task completion  
- 💾 Offline data storage using Room  
- ⚡ Reactive UI with Jetpack Compose  

---

## 🛠 Tech Stack

- **Kotlin** – Application logic  
- **Android Studio** – Development environment  
- **Jetpack Compose**
  - LazyColumn
  - Material components
- **MVVM Architecture**
  - ViewModel
  - State management
- **Room Database** – Local persistence  

---

## 🧠 How the App Works

1. UI is built using **Jetpack Compose**
2. Tasks are displayed using **LazyColumn**
3. User actions update the **ViewModel**
4. Room database stores task data locally
5. UI automatically reacts to state changes
6. When a task is completed:
   - A popup dialog appears
   - Task status is updated in the database
